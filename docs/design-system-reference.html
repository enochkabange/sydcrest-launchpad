Design System

The token layer, primitives and usage rules the platform is built from — derived from the Beet Agency brand guideline, with every contrast ratio measured rather than assumed.

Version 1.0 · August 2026

The mark

Four angled bars carrying two gradients — a cool blue-to-black pair and a warm orange-to-yellow pair. The geometry here was measured from the vector paths inside the brand guideline, so this is the real artwork rather than a trace of a PNG.

Clear space is one mark-height on every side. Never recolour the bars, change their angles, or reorder them.

On dark grounds, swap the variant

The full-colour mark is for light surfaces only — its two cool bars run to near-black, so on ink or Sea Blue they disappear and the mark loses half its geometry. On dark grounds use variant="onDark" (right-hand tiles above): the cool bars go solid white, the warm bars keep their gradient. This is the brand book's own treatment on the app icons, not an invention.

Known gap — the wordmark

No Gilroy web licence is held, so the lockup's wordmark is set in type rather than vectorised from the original artwork. It is close, not exact. The fix is one email: ask Beet Agency for the vector source (.ai, .svg or .eps) — they will have it. Until then, keep using the supplied files for print and social.

The orange rule

Brand orange is 2.34:1 on white. It fails AA for text. This is the single most important constraint in the system — and the brand book agrees with it, incidentally: its own website mockup uses a charcoal button, not an orange one.

Orange as a fill — progress accents, active states, decorative shapes.

Orange with ink text on top (7.13:1). This is the accent button.

Orange as text on charcoal or ink (5.39:1 / 7.13:1).

Orange text on white. Use orange-800 — 5.33:1.

White text on orange. That is 2.34:1. Invert to ink.

Typography

The brand font is Gilroy, which is commercial and not licensed for web. The platform uses Urbanist — picked because it shares Gilroy's distinctive single-storey a and near-identical letter widths, unlike Figtree or Poppins. One 28KB variable file covers all six Gilroy weights, which matters for learners on mobile data.

Status, and why orange isn't one

Brand orange means "SydCrest", never "caution". If it signalled both in progress and warning, a learner would read their own progress bar as a problem. So orange is absent from the status set entirely, and warning sits at hue 45° — clear of the accent's 33°.

Icons

Lucide glyphs behind a semantic layer. Components ask for what a thing means — <Icon name="lesson" />, not <BookOpen /> — so changing the picture for "project" is one line rather than a find-and-replace across the app.

The registry is the vocabulary

Only registered icons are bundled, and an unknown name throws in development rather than rendering nothing — a silently-missing icon is the same class of bug as a utility class that never generates: invisible in review, obvious to a user.

48 icons cost ~27KB raw, ~8KB gzipped. Lucide ships 6,059 of them; tree shaking is the only thing between that and megabytes, which is why the registry uses named imports rather than a dynamic lookup.

Motion

One rule governs everything: animate transform and opacity only. Those composite on the GPU. Animating height, width or background-position forces layout or paint on every frame — the difference between a smooth interface and a stuttering one on the phones this cohort actually owns.

The launch loader

The logo's four bars rise along the axis they already point down, staggered 110ms apart. This is the only place stagger is used — scattering it would spend the idea.

Skeletons pulse, they do not shimmer

A sweeping shimmer needs a full-width layer moving under every block. On a list of twenty lesson cards that is real per-frame work on a cheap phone. Opacity reads the same and costs almost nothing. Every duration here collapses to zero under prefers-reduced-motion — nothing depends on animation to be usable.

Layout and navigation

The responsive decision is made once, in AppShell, so no screen re-litigates it.

BreakpointNavigation
< 768pxBottom tab bar. The majority device is a phone held one-handed, so primary navigation belongs under the thumb — not behind a hamburger in the top-left corner, the hardest pixel on a phone to reach.
≥ 768pxPersistent sidebar. Space exists, so spend it on orientation rather than hiding navigation behind a click.

No hamburger menu at any breakpoint

Every primary destination is always one tap away. The tab bar carries env(safe-area-inset-bottom) so it clears the iOS home indicator, and <main> carries matching bottom padding so content is never trapped underneath it. A skip link is the first tab stop on every page.

Lesson content

The surface a learner spends twelve weeks inside. Body type is 17px at 1.7 line-height, capped near 68 characters — wider is measurably harder to read on a phone at arm's length.

Stepped, not scrolled

A lesson is a sequence of short steps with a visible "4 of 12", each ending in a question rather than a Next button. A 3,000-word page gets abandoned; twelve steps get finished. Completion rate is the pilot's entire thesis, so this is a product decision rather than a layout preference.

Steps carrying a check gate advancement until answered.
Gating every step — that turns a lesson into an exam.
The explanation shows on a correct answer too. Being right for the wrong reason is the failure mode nobody catches.
Scoring a wrong answer. You retry; it is not a dead end.

Callout is not Alert

They look different on purpose and must never blur. Alert is the system reporting what happened — "submission failed". Callout is the author speaking to the learner — "watch out for this". Callout kinds are note, tip, warning, and task: a concrete thing to go and do, which is where curriculum turns into practice.

Why there is no syntax highlighter

Prism costs ~22KB gzipped once you add core plus markup, css and javascript — roughly a 30% increase on the entire app bundle, paid by every learner on metered data, on every visit. For colour.

So highlighting happens once, server-side, when a lesson is saved, and the result is stored with the lesson. The client ships zero highlighter. A ~40-line fallback tokenizer covers the three languages the curriculum uses — and it produces React elements rather than HTML strings, so injection is structurally impossible. Token colours stay to four hues; a rainbow highlighter fights the brand and reads as noise at 14px on a low-DPI panel.

The accessibility floor

Non-negotiable for the pilot.

  • Every text and background pair clears 4.5:1, or 3:1 for text at 24px and above.
  • Colour is never the only signal — it is always paired with an icon, label or shape.
  • One focus treatment everywhere: a 2px Sea Blue ring at 2px offset.
  • prefers-reduced-motion is respected globally.
  • Form errors use aria-invalid and aria-describedby, not just a red border.
  • Body text never drops below 16px for content a learner has to read.
