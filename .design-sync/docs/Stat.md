# Stat

A real, sourced number with its label. Never a target or a guess.

## When to use

Use only for counts the database or a cited source backs. With nothing real to show, write an honest sentence instead.

## Props

value: string; label: string.

## Where it is used

the (marketing) layout, /about, /partners
