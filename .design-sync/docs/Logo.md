# Logo

The full lockup: the real four bar mark plus the wordmark set in Urbanist.

## When to use

Use in headers and footers. `tone="ink"` on light and themed surfaces (the mark follows the theme), `tone="inverse"` on Sea Blue, charcoal or photography. Keep clear space equal to the mark's height. For print and social use the Logos asset files: the wordmark here is set in type.

## Props

size?: number (default 40); tone?: "ink" | "inverse"; variant?: "auto" | "color" | "onDark" | "mono"; className?: string; plus <span> props.

## Where it is used

App sidebar, app top bar, site header and footer
