# TalentCard

One learner as organisations see them in the talent directory: never an email or phone number.

## When to use

Use on /talent (with `href`, the card is the link), /talent/[id] and the learner's own preview (`full`). `action` adds a contact button.

## Props

row: TalentRow; href?: string; full?: boolean; action?: ReactNode.

## Where it is used

/talent, /talent/[id], /talent/me

## Source

`src/components/business/talent-card.tsx`. Exported as `TalentCard`.
