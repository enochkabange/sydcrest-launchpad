# ShareCertificate

The public verification link with a copy button, plus LinkedIn's add a certification form prefilled.

## When to use

Use inside an issued CertificationCard. Nothing is sent to LinkedIn by SydCrest: it is a plain link out.

## Props

url: string; title: string; verificationId: string; issuedAt: string.

## Where it is used

CertificationCard on /certificates

## Source

`src/components/certificates/share-certificate.tsx`. Exported as `ShareCertificate`.
