# ChapterStatusBadge

A chapter's status as a pill: active, launching, paused, or planned with a label.

## When to use

Use on chapter cards and pages. Exported from the code as StatusBadge.

## Props

status: string; label?: string.

## Where it is used

/chapters, /chapters/[slug], /admin/chapters
