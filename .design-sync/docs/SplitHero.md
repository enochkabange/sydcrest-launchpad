# SplitHero

Words beside a visual from lg (a 7:5 grid); phones and tablets stack them, words first.

## When to use

Use for heroes and page headers that carry a visual or a block of facts. PageHeader uses it when given an `aside`.

## Props

children: ReactNode (the words); visual: ReactNode; className?: string.

## Where it is used

the (marketing) layout
