# Initials

A letter avatar. SydCrest does not invent photos.

## When to use

Use wherever a person appears without their own photo: posts, leaderboards, rosters, talent cards. Sizes sm (40px) and lg (64px).

## Props

name: string; size?: "sm" | "lg".

## Where it is used

PostCard, leaderboards, /dashboard rail, TalentCard, org pages

`src/components/social/profile-bits.tsx`. Exported as `Initials`.
