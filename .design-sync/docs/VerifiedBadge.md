# VerifiedBadge

"Verified by SydCrest": the admin's trust flag on an expert. It says SydCrest vouches, not that an identity was checked.

## When to use

Use beside an expert's name when is_verified is set. Verified skills are a separate badge (VerifiedSkillBadges).

## Props

No props.

## Where it is used

/experts/[slug], ExpertCard

`src/components/experts/expert-bits.tsx`. Exported as `VerifiedBadge`.
