# TabList

The phone tab bar under md: Home and the four hubs, fixed to the bottom, clear of the home indicator.

## When to use

Rendered by PhoneTabBar. Primary navigation sits under the thumb; there is no hamburger. Hidden from md.

## Props

pathname: string | null.

## Where it is used

PhoneTabBar in src/app/(app)/layout.tsx

## Source

`src/components/app-shell/nav.tsx`. Exported as `TabList`.
