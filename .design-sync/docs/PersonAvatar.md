# PersonAvatar

A member's own photo when they set one, else their initials.

## When to use

Use in booking lists and threads. Sizes sm (36px) and md (48px).

## Props

name: string; avatarUrl: string | null; size?: "sm" | "md".

## Where it is used

/bookings, /bookings/[id]

## Source

`src/components/bookings/bits.tsx`. Exported as `PersonAvatar`.
