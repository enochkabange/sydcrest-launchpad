# BriefFacts

Budget, place, deadline and pitch count with icons, each only when there is a value.

## When to use

Use on brief cards and the brief page. Budgets are indicative and in cedis.

## Props

brief: Brief; showPitches?: boolean (default true).

## Where it is used

BriefCard, /briefs/[id]

## Source

`src/components/briefs/brief-bits.tsx`. Exported as `BriefFacts`.
