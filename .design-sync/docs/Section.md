# Section

A full width band with a heading and intro; `layout="split"` sets the heading beside the content from lg.

## When to use

Use for every band of a marketing page. `tone="sunken"` alternates bands. Headings use text-h2, intros text-body.

## Props

title?: string; intro?: ReactNode; children?: ReactNode; tone?: "plain" | "sunken"; id?: string; layout?: "stacked" | "split".

## Where it is used

the (marketing) layout, /about, /accessibility, /business, /impact, /partners
