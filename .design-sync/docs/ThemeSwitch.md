# ThemeSwitch

One tap between light and dark; both icons are in the markup and CSS shows the right one.

## When to use

Use in the top bar, the sidebar and the site header. Follow my device and the other display settings live on /settings. In this preview it flips the page theme.

## Props

className?: string.

## Where it is used

AppSidebar, AppTopBar, SiteHeader

## Source

`src/components/display/theme-switch.tsx`. Exported as `ThemeSwitch`.
