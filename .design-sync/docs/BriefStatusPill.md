# BriefStatusPill

A brief's status as a tinted pill: Open, Closed, Awarded or Cancelled.

## When to use

Use in the poster's own lists (/briefs/mine).

## Props

status: string ("open" | "closed" | "awarded" | "cancelled").

## Where it is used

/briefs/mine
