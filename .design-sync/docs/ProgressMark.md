# ProgressMark

The status icon beside a node in the outline: done, in progress or not started, with the word for screen readers.

## When to use

Use wherever a node's status shows as an icon. Colour never carries the meaning alone: each status has its own shape and a text label.

## Props

status: "done" | "in_progress" | "not_started".

## Where it is used

OutlineView (via ViewNodeMark)
