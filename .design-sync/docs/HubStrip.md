# HubStrip

A compact row of a group's destinations for a hub whose landing page is one of them (Community: the feed).

## When to use

Use at the top of the community pages; `current` marks the destination the page belongs to.

## Props

id: "learn" | "mentors" | "community" | "earn" | "you"; current: string (an href).

## Where it is used

/community

`src/components/app-shell/hub.tsx`. Exported as `HubStrip`.
