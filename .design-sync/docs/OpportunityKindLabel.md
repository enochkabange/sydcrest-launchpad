# OpportunityKindLabel

An opportunity's kind as a small info pill: Job, Internship, Scholarship, Grant or Gig.

## When to use

Use on opportunity cards and pages. Exported from the code as KindLabel.

## Props

kind: string.

## Where it is used

/opportunities/[slug], OpportunityCard

## Source

`src/components/opportunities/meta.tsx` (exported there as `KindLabel`). Exported as `OpportunityKindLabel`.
