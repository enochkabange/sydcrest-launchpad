# StepGraphic

A small numbered step glyph for the stages of a process.

## When to use

Use beside the steps of a how it works band; `index` picks the step.

## Props

index?: number (default 0); className?: string (default size-11).

## Where it is used

the (marketing) layout

## Source

`src/components/brand/illustrations.tsx`. Exported as `StepGraphic`.
