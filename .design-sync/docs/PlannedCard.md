# PlannedCard

A northern capital with no chapter yet: honest, dashed, no link and no join button.

## When to use

Use in the /chapters grid for planned cities. `first` marks the city being set up first.

## Props

city: string; regionLabel: string; first: boolean.

## Where it is used

/chapters

## Source

`src/components/chapters/chapter-bits.tsx`. Exported as `PlannedCard`.
