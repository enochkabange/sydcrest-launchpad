# SectionAccent

The small bar accent above a page or section heading.

## When to use

Use once above a page title (PageHeader does it for you). Decorative only.

## Props

className?: string (default size-10).

## Where it is used

/events/[slug], /roadmaps/[slug], /skills/[slug]
