# StudyBuddyPrompt

What signed out visitors see in place of the chat: why Study Buddy helps, then sign up and sign in.

## When to use

Use on public topic pages for visitors. Static; on prerendered pages use TopicStudyBuddy, which checks the session in an island.

## Props

nodeTitle: string; next?: string (where sign in returns to).

## Where it is used

Public topic pages (via TopicStudyBuddy)
