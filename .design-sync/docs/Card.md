# Card

A bordered card with an optional eyebrow, an h3 title and body copy.

## When to use

Use for marketing grids (stages, benefits, partners). Not for app records: those have their own cards (EventCard, ExpertCard...).

## Props

title: string; children: ReactNode; eyebrow?: ReactNode.

## Where it is used

the (marketing) layout, /about, /accessibility, /admin/cohorts, /admin/cohorts/[id], /business

## Source

`src/components/marketing/section.tsx`. Exported as `Card`.
