# SkipLink

The first tab stop on every layout with navigation: jumps to the main content.

## When to use

Render first in every layout with navigation. Visually hidden until focused. Tab into this preview to see it.

## Props

No props.

## Where it is used

the (app) layout, the (marketing) layout, the (public) layout, /admin
