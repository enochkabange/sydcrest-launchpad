# ReplyCard

One reply in a thread: byline, safe markdown, reactions and tools.

## When to use

Use under a post on /community/post/[id]. Reactions are read only once the post is closed or the reply hidden.

## Props

reply: ReplyView; viewer: Viewer; postOpen: boolean.

## Where it is used

/community/post/[id]
