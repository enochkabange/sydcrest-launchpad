### Approach decision

Cross platform frameworks (Flutter or React Native) appear in 16 of 20 adverts; native only adverts are A7, A8, R5 and R7. In Ghana specifically, Flutter (A1 to A6) and React Native (A4 to A6, A9 to A12) are roughly even, and the one clearly entry level Flutter advert is a National Service role (A2). We chose **Flutter** as the main path because: it is cross platform like the majority of adverts; it has an entry level Ghanaian signal; DartPad lets learners practise Dart and simple Flutter on a phone browser, which fits SydCrest's phone first rule; and Dart is a single, typed first language. React Native is presented as the alternative for learners coming from the frontend track (it is the most frequent single framework, so the founder may want a React Native variant later). Kotlin is an optional final node because 11 adverts name it, often as a plus alongside a cross platform framework.

## Gaps and changes

* **New track**, so the outline was built from the research rather than revised. 29 nodes in 7 sections.
* **Adverts demanded skills a phone first outline might skip**: Git (9), testing (7), CI/CD (7) and store release (8). Git, testing and publishing each got a node. **CI/CD** is mentioned only in passing (inside testing and release context) and not given its own node; it appears mostly as "preferred" and in mid or senior roles.
* **iOS / Swift** (7 adverts) is not covered beyond noting that Flutter builds for iPhone too; building and publishing for iPhone needs a Mac, which is out of reach for most learners. Worth a founder decision.
* **React Native** is the single most frequent framework (12). We kept Flutter as the main path for the phone first and entry level reasons above. A React Native variant of the UI and state nodes would be a natural follow up.
* **Offline first, mobile money, SMS and USSD, low end Android** have weak or no advert signal but are kept for SydCrest's learners and context; the coverage table says so explicitly.
* **Ghanaian advert dates:** most Ghanaian mobile adverts found were older or closed; current local demand appears thin and Accra or Kumasi based. Remote roles open to Ghana were current but mostly mid or senior. The lessons avoid claiming that jobs are plentiful.
* **ESCO** was down; O*NET has no mobile specific occupation, so WorldSkills headings and official course outlines were used as framework signals.
